# 사전 등록 (데이터를 보기 전에 정한 기준)

이 파일의 값은 **해당 데이터를 보기 전에** 채우고 커밋한다. 커밋 시각이 "결과 보기 전에 정했다"는 기록이다.
값을 바꾸면 덮어쓰지 말고 아래 변경 기록에 날짜·이유와 함께 남긴다.

## 첫 이틀의 둘째 날 전 확정

| 항목 | 값 | 이유 (한 줄) | 확정일 |
|---|---|---|---|
| 순위 깊이 | **1~200위** (201위 이하는 "200위 밖"으로만 봄. 이미 받은 1~1000위 캐시도 분석엔 200위까지만) | YES24 문의 범위(약관 축적 조항)에 맞춤. 계획서 원래 설계(알라딘 Top200, 101~200위 체류 공변량)와 같음. 진입 그룹 숫자를 보기 전에 정함 | 2026-11-04 |
| 진입 정의: 일별 순위를 주 단위로 묶는 방법 (예: 그 주 N일 이상 Top100 / 주중 최고 순위) | | | |
| 순위 카테고리: YES24 소설/시/희곡 합산(001001046) 사용 여부 | | | |
| 이벤트 스터디 그룹 경계 ("순위권 밖에서 진입" vs "하위권 체류 후 진입"의 구간) | | | |
| 출간 경과 제외: 메인 규칙 4주 / 8주 (계획서 4-2는 4주, 5-3 창 때문에 사실상 8주) | | | |
| 출간일 소스: 모집단 전체의 실제 출간일 (YES24 상품 검색 / 서지 API 발행예정일). **순위 응답의 출간일은 쓰지 않음** (순위권 책에만 있어 결과로 고르는 꼴) | | | |
| 키워드 규칙 (3-3): 제목 단독 포함 여부, 사전 단어 제목 처리 | | 20권 검토 후, 진입 그룹 데이터 보기 전 | |
| X: 선행성 판정 "1주 이상 앞섬" 비율 (5-1 해석 기준) | | | |
| Y: 이벤트 스터디 Go 기준, 200위 밖 진입 그룹 합산 비율 CI 하한 (5-1 절차 4) | | | |

진입 정의는 **대표 정의 1개를 근거와 함께 고정**하고, 나머지 후보는 민감도로만 쓴다. 데이터로 비교해서 고르지 않는다.
근거는 순위 쪽 성질(하루하루 흔들림, 하루 누락에 강한지)로만 대고, 검색 선행 결과나 특정 책이 포함되는지는 보지 않는다.

## 변경 기록

- 2026-11-03: 0단계 표의 알라딘 행을 YES24로 교체 (알라딘 OpenAPI 2026-11-01 종료). 기준 값 변경 아님
- 2026-11-04: "둘째 날 전 확정" 표에 진입 정의·순위 카테고리·그룹 경계 3행 추가 (결과 소스가 일별 Top1000으로 바뀌어 새로 생긴 결정). 값은 아직 비어 있음
- 2026-11-04: 출간 경과 제외·출간일 소스·키워드 규칙 3행 추가
- 2026-11-04 **이 기준들을 정하기 전에 이미 본 것** (숨기지 않고 기록): 수족관 1권의 2024년 월요일 39일 YES24 순위 궤적(01-29 66위, 이후 244~1000위 밖, 7월 말 913→385→263), 같은 39일 캐시의 페이지 길이, salePoint 값. 진입 그룹 전체의 순위·검색량, 대조군은 보지 않음. 수족관이 포함되도록 정의를 맞추지 않는다
- 2026-11-04 정정: 위 "이미 본 것"의 "이후 244~1000위 밖"은 부정확. 01-29(66위) 이후 최고는 02-05 181위, 7월 말 913→385→263
- 2026-11-04: 순위 깊이 1~200위로 확정 (YES24 1:1 문의 발송, 범위 1~200위·약 2,500회 + 상품 상세 출간일 조회). 그룹 경계 행은 이 깊이를 전제로 정함: "200위 밖"은 201위와 5,000위를 구분 못 함(계획서 원래 알라딘 Top200 설계와 같은 한계)
- 2026-11-05 정정: 11-04 줄의 "그룹 경계 행은 이 깊이를 전제로 정함"은 "정할 때 이 깊이를 전제로 한다"의 뜻. 그룹 경계 행은 아직 비어 있음
- 2026-11-05: **YES24가 수집·저장 불가로 답함 → 결과 소스 없음.** "순위 깊이 1~200위" 행과 YES24 전제(카테고리 001001046, 일별 진입 정의, 그룹 경계)는 **무효.** 결과 소스를 새로 정한 뒤 해당 행을 다시 채움. 이미 본 것(수족관 YES24 궤적 등)의 기록은 유지
