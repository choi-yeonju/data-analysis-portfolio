### 1. Olist 고객 불만 조기경보 — 핵심 결과
- 배송 지연은 주문 시점 정보로 기저율 수준밖에 맞히지 못했다. 2018-08에 예상 배송일이 약 5일 짧아지면서 지연 라벨 기준 자체가 흔들린 것을 추적했다.
- 저평점은 약하지만 기간 내내 기저율 위의 신호가 있었고(1.35배), 그 대부분은 배송비 합계 하나로 설명됐다.
- 지연이 아닌 저평점 리뷰를 직접 분류한 결과, 가장 큰 불만은 구성품 누락·오배송·일부만 도착(32.9%)이었다.
- → [README](olist/README.md) · [상세 보고서](olist/docs/final_report.md)

### 2. 취준생 장기재직 지원 서비스 — 담당 역할
- 잡플래닛 리뷰 분석과 머신러닝 파트를 맡았다. 7개 영역 키워드 사전, 랜덤포레스트 3분류(추천 / 조건부 추천 / 비추천, F1 0.83).
- 리뷰 전처리 중 "포괄임금제" 같은 복합명사가 쪼개지는 오류를 찾아 사용자 사전과 표현 정규화로 고쳤다.
- Streamlit 추천 서비스에서 분석 결과와 기업 상세 정보를 연결했다.
